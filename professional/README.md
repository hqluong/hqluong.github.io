# Hung Luong — professional portfolio

This folder is a separate job-search version of Hung Luong’s website, focused on Senior Digital Marketing, Performance Marketing, Digital Growth, and E-commerce opportunities.

## Publish beside the academic site

1. Open `https://github.com/hqluong/hqluong.github.io` and sign in.
2. Choose **Add file → Upload files**.
3. Drag this entire `professional` folder onto the upload page. Keep the folder name exactly `professional`.
4. Commit the upload directly to the `main` branch.
5. Wait a few minutes, then open `https://hqluong.github.io/professional/`.

The existing academic homepage at `https://hqluong.github.io/` remains unchanged.

## Included

- `index.html` — professional portfolio content
- `styles.css` — responsive design
- `assets/hung-luong-headshot.jpg` — professional headshot
